# Text Difference Checker
A Python Flask web application that compares two text inputs and identifies differences.

## Technologies
- Python and Flask
- Docker
- GitHub Actions for Continuous Integration
- Render for cloud deployment
- Postman for API testing

## Live Application
https://text-difference-checker.onrender.com

## Deployment
Application uses GitHub Actions for automated testing and Docker image publishing, followed by Render deployment after CI checks pass.

Deployment: Automated through GitHub Actions, Docker Hub and Render
